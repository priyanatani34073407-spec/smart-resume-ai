# 🚀 Smart Resume AI Analyzer

An AI-powered web application that analyzes resumes and provides job matching insights, ATS score, and improvement suggestions.

---

## 🔐 Features
- User Authentication (Login/Register System)
- Resume Upload (PDF)
- AI-Based Resume Analysis
- Role-Based Skill Matching
- ATS Score Calculation
- NLP Job Description Matching
- Smart Suggestions for Improvement
- Report Saving & Ranking System

---

## 🛠 Tech Stack
- Python
- Streamlit
- NLP (Scikit-learn)
- AWS Concepts
- Matplotlib
- ReportLab

---

## 📊 Key Highlights
- 🎯 Identifies best job role based on skills  
- 📈 Calculates ATS Score  
- 🔗 Matches resume with job description  
- 💡 Suggests missing skills  
- 🏆 Provides ranking among users
